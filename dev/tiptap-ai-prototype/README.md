# Стенд совместимости Tiptap AI Toolkit

Временный стенд проверяет, может ли публичный AI SDK для Tiptap 3 описать настоящую схему редактора TraceX и какие данные сохраняются при обработке документа этой схемой. Это отдельный npm-проект, не зарегистрированный в Rush.

## MVP собственного ops-слоя

Для проверки ядра собственного MCP-редактора на настоящем `ServerKit` и двух Yjs-репликах:

```bash
rtk proxy bash dev/tiptap-ai-prototype/run.sh --check-ops
```

Режим использует исходники `@hcengineering/text-agent/src/operations` и установленные зависимости приложения. Установка пакетов и платный AI SDK не нужны. Возможности, результаты и границы проверки: [ops-mvp.md](./ops-mvp.md).

## Сравнение способов адресации для собственного MCP-редактора

Для сравнения ссылок на идентичность Yjs и UUID запустите:

```bash
bash dev/tiptap-ai-prototype/run.sh --compare-identities
```

Это отдельный режим без Tiptap AI и сетевых запросов, использующий установленные зависимости приложения. Он не меняет прикладную схему и проверяет только искусственные документы. См. [сравнение и ограничения](./identity-comparison.md); подробные данные создаются в `results/identity-comparison.json`.

## Запуск

Из корня репозитория:

```bash
bash dev/tiptap-ai-prototype/run.sh
```

Скрипт использует Node >=20 <25 из PATH или установленного nvm. Он проверяет установленные версии пакетов Tiptap перед запуском. При отсутствии зависимостей или несовпадении с манифестом выполняется `npm ci` с отключёнными установочными скриптами пакетов. Зависимости Rush и корневые lock-файлы не меняются. Сборка, форматирование, база данных, браузер и сервер приложения не нужны.

Стенд копирует текущие исходники общего `ServerKit` и настоящего клиентского QMS mark в игнорируемую папку `.runtime/`, затем загружает TypeScript во время выполнения. Проверяется код репозитория, а не вручную воссозданные определения узлов. Импорт общего QMS mark из клиентского расширения направляется на его скопированный исходник. Хеши исходников записываются в отчёт. Сравниваются стандартный `ServerKit` и профиль с клиентским расширением того же общего QMS mark; полный набор расширений клиентского редактора здесь не подключён.

Манифест фиксирует Tiptap 3.33.0 и `@tiptap/ai-toolkit` 0.4.1. Lock-файл формируется npm с настоящими контрольными суммами архивов. Версии фактического прогона записываются в `results/report.json`; краткий отчёт приведён в [результатах](./RESULTS.md).

## Что проверяется

- Загрузка настоящего `ServerKit` вместе с публичным AI-расширением без браузера.
- Совпадение установленных версий Tiptap с манифестом стенда.
- Чтение документа из JSON и обратная запись для статической серверной схемы и профиля с настоящим клиентским QMS mark.
- Сохранение QMS ID стандартной серверной схемой с Toolkit и без него.
- `getEditorContext()`, явные описания собственных узлов со схемами атрибутов Zod и метод `addJsonSchemaAwareness()` на самом расширении.
- Сохранение контекста в JSON и восстановление схемы ProseMirror.
- Вставка перед защищённым содержимым и замена отдельного абзаца обычными транзакциями ProseMirror с проверкой сохранности ссылок, изображений, комментариев и таблицы.
- Отклонение неизвестных узлов и недопустимой вложенности таблицы средствами ProseMirror.

`fixture.json` содержит только искусственные данные. Стенд не загружает изображения и встроенные объекты по указанным в нём адресам.

## Где смотреть результат

Игнорируемая папка `results/` содержит подробные данные:

- `report.json`: проверки, наблюдения, версии, область проверки и хеши исходников.
- `server-roundtrip.json` и `qms-profile-roundtrip.json`: сравните mark `node-uuid` во втором абзаце.
- `editor-context-baseline.json`, `editor-context-enriched.json`, `editor-context-extension-owned.json`: настоящий результат работы SDK.
- `after-native-edits.json`: документ после локальных транзакций.

Выводы и ограничения описаны в [RESULTS.md](./RESULTS.md).

## Границы проверки

Публичный SDK предоставляет контекст редактора и расширение для атрибутов `_hash`. Платный движок выполнения AI tools в него не входит. Локальные транзакции этого стенда не являются вызовами AI tools. Не проверяются LLM, закрытый клиентский Toolkit, настоящий процесс QMS, работающий collaborator, одновременные изменения и их согласование, отображение HTML и полное совпадение схем клиента и сервера.

Названия и описания в расширенном контексте объясняют тестовые данные; они не предоставляют права и не запрещают изменение защищённых данных. Описание всех собственных расширений TraceX остаётся отдельной задачей. Успешное чтение JSON может незаметно удалить атрибуты, которых нет в схеме.

## Необязательная проверка настоящего API

Этот режим не запускался: по выбранному условию проверяется только публичный SDK. Когда появится платный доступ, задайте Tiptap Access Control JWT через `TIPTAP_AI_TOKEN`; для собственного размещения сервиса при необходимости задайте `TIPTAP_AI_URL`. Затем выполните:

```bash
bash dev/tiptap-ai-prototype/run.sh --live
```

Режим получает определения настоящего `tiptapQuery` и выполняет одну заранее заданную текстовую правку переданного JSON. Он не вызывает LLM и не сохраняет документ в рабочее пространство. Токен не выводится и не сохраняется. Результаты записываются в игнорируемые файлы. При ошибке HTTP выводятся статус и код ошибки.

## Что делать дальше

1. Вручную проверить QMS-комментарии в приложении: сохранение и повторное открытие документа, несколько комментариев на одном фрагменте, переход к комментарию и ввод рядом с отмеченным текстом. Общий mark уже используется сервером и клиентом; автоматические проверки описаны в результатах.
2. Если продолжаем с коммерческим Toolkit, получить доступ и проверить `--live` на искусственном документе.
3. После проверки API отдельно проверить агентный сценарий, запись через наш collaborator и одновременное редактирование. Успешные локальные проверки схемы не подтверждают эти сценарии.

Источники: [контекст редактора](https://tiptap.dev/docs/ai/ai-toolkit/api-reference/editor-context), [собственные узлы](https://tiptap.dev/docs/ai/ai-toolkit/advanced-guides/custom-nodes), [REST API](https://tiptap.dev/docs/ai/ai-toolkit/api-reference/rest-api).
